# Superstore Sales Dashboard | Power BI

## Overview
An interactive Power BI dashboard built to analyze Superstore sales performance, quantity sold, and profitability.

## Features
- KPI cards for Total Sales, Quantity, and Total Profit.
- Sales analysis by category and region.
- Profit distribution across product categories.
- Sales trends over time.
- Top 5 customers by sales and profit.
- Interactive Region and Category slicers.

## Tools Used
- Microsoft Power BI
- Superstore Dataset
